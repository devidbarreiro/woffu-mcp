# woffu-mcp

## Register
brand

## Product Purpose
Open-source MCP server that lets any AI agent (Claude, Cursor, Windsurf, Hermes, VS Code) clock in/out on Woffu, the popular Spanish HR platform. First and only MCP integration for Woffu. Published on npm as `woffu-mcp`.

## Users
- **Primary:** Developers in Spain/Latam who use Woffu at work and want to clock in from their coding agent without opening the Woffu web app.
- **Secondary:** DevOps/IT leads who want to automate attendance for their team.
- **Tertiary:** MCP enthusiasts exploring what's possible with the protocol.

## Brand Voice
- Technical but approachable. Not corporate.
- Slightly irreverent — clocking in from your terminal is a power move.
- Bilingual context: users are Spanish-speaking developers, but the package and docs are in English.

## Tone
Confident, concise, developer-first. No fluff. Show don't tell.

## Anti-references
- Generic SaaS landing pages with gradient heroes and big numbers
- Corporate HR software aesthetics (teal + white + stock photos)
- Overly playful/cute developer tool pages
- Dark mode terminal aesthetic (too obvious for a dev tool)

## Strategic Principles
- The landing page should feel like a well-crafted README that you can scroll through
- Code examples are the hero, not screenshots
- Make it obvious this is a real tool that works today, not vaporware
- The MCP ecosystem is new — explain it briefly for people who don't know what MCP is
- npm install command should be copy-pasteable within 5 seconds of landing
